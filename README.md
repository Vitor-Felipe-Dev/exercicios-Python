# exercicios-Python

Repositorio destinado à prática de logica de programação e ao desenvolvimento em Python.

## Exercícios

### 01-Verificador de idade
Validação de idade utilizando estruturas condicionais, laços de repetição e tratamento de execeções.

### 02-Verificador de nota
Validação de notas escolares, identificando aprovação ou recuperação

## Conceitos praticados

-Variaveis
-Entrada e saída de dados
-Condicionais (if, elif, else)
-Laços de repetição (while)
-Tratamento de exceções (try,except)
-Conversão de tipos

## Objetivo

Registrar minha evolução nos estudos de python através de exercícios práticos
