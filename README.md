
# Exercícios Python

Repositório destinado à prática de lógica de programação e
ao desenvolvimento dos meus conhecimentos em Python.

## Exercícios

### 01 - Verificador de idade
Validação de idade utilizando estruturas condicionais,
laços de repetição e tratamento de exceções.

### 02 - Verificador de nota
Validação de notas escolares, identificando aprovação
ou recuperação.

### 03 - Analisador de números 
Identificação de números pares e impares,
utilizando laços de repetição,
condicionais,
contadores e acumuladores.

### 04 - Tabuada automática
Geração de tabuadas utilizando laços de repetição 
aninhado (for dentro de for) e f-strings

## Conceitos praticados

- Variáveis
- Entrada e saída de dados
- Condicionais (if, elif, else)
- Laços de repetição (while)
- Tratamento de exceções (try/except)
- Conversão de tipos

## Objetivo

Registrar minha evolução nos estudos de Python
através de exercícios práticos.
